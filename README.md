Pong-Unity

A simple 2D Pong game built with Unity and C#.

Overview

This repository contains a classic Pong game featuring paddle controls, ball physics, and score tracking. The project serves as a small Unity game project for exploring and learning gameplay programming.

Features

Classic Pong gameplay

Paddle movement and ball physics

Score tracking

Multiple game modes (verify against the actual project)

Built With

Engine: Unity

Language: C#

Version Control: Git and GitHub

Getting Started

Clone or download this repository.

Open Unity Hub.

Select Add Project from Disk and choose the project folder.

Open the project using a compatible Unity version.

Open the main scene and press Play.

Project Structure

Assets/ — Game scripts, scenes, and assets

Packages/ — Unity package dependencies

ProjectSettings/ — Unity project configuration
